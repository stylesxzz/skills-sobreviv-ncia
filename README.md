# Survival & Civilization Reconstruction Skill

Skill de conhecimento prático para agentes de IA sobre preparação para emergências, sobrevivência responsável e reconstrução gradual de capacidades comunitárias.

> **Estado da fonte:** esta versão inicial NÃO foi extraída nem validada contra *The Book: The Ultimate Guide to Rebuilding Civilization*. O PDF não foi fornecido nesta conversa. O conteúdo abaixo é uma estrutura original de orientação geral, não uma reprodução nem um resumo fiel do livro.

## Instalação

Com o CLI do ecossistema Agent Skills:

```bash
npx skills add stylesxzz/skills-sobreviv-ncia --skill survival-reconstruction
```

Se o CLI solicitar o nome da skill, selecione `survival-reconstruction`.

## Conteúdo

- `skills/survival-reconstruction/SKILL.md` — instruções centrais do agente.
- `knowledge/` — guias temáticos de referência.
- `procedures/` — modelos de procedimentos e listas de verificação.
- `safety/` — limites, triagem de risco e critérios de encaminhamento.

## Princípios

1. Proteger vidas antes de proteger bens.
2. Priorizar água segura, abrigo, temperatura, higiene, comunicação e primeiros socorros básicos.
3. Separar fatos estabelecidos, estimativas e hipóteses.
4. Nunca inventar dosagens, limites técnicos, propriedades de materiais ou garantias de potabilidade.
5. Adaptar recomendações ao clima, legislação, recursos, habilidades e riscos locais.
6. Para medicina, eletricidade, estruturas, produtos químicos e máquinas, indicar quando é necessário profissional qualificado.
7. Citar fontes externas confiáveis quando a resposta depender de informação atual ou de alto risco.
